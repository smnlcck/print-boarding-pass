# Aer Lingus boarding pass printer

A motion concept for the Aer Lingus mobile boarding pass: the pass prints out of a slot and settles in place, with all the flight details left on screen. Use Replay or the print button to run it again.

- **Live page:** https://smnlcck.github.io/aer-lingus-boarding-pass/
- **Video:** [`media/aer-lingus-boarding-pass-printer.mp4`](media/aer-lingus-boarding-pass-printer.mp4) (780×1688, one print, about 7 seconds)

`index.html` is self-contained (HTML, CSS and JS in one file, logo and QR code inlined). Add `?record=1` to the URL to show only the phone screen without the frame and controls.

Passenger details and the QR code are placeholder data.
